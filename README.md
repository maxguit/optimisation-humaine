# Optimisation humaine

Application personnelle de routine physique, publiée avec GitHub Pages.

## Déploiement

Le site est empaqueté en deux parties binaires :
- `OPTIMISATION_HUMAINE_V13_PWA.part-00`
- `OPTIMISATION_HUMAINE_V13_PWA.part-01`

Le workflow GitHub Pages les réassemble, vérifie l'archive, extrait la PWA et publie automatiquement le site.

La source applicative publiée contient 45 vidéos MP4, le manifeste PWA et le service worker pour l'utilisation mobile et le cache hors ligne.
